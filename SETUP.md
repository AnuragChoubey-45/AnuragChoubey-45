# Setup notes

This folder is prepared for the public profile repository `AnuragChoubey-45/AnuragChoubey-45`. Copy its contents to the repository root.

- The README and SVGs use CSS and SMIL only; images are embedded as PNG data URIs, and Space Grotesk / IBM Plex Mono WOFF2 fonts are embedded in each SVG.
- Font licenses are included in `assets/font-licenses.txt`.
- The portrait uses your enhanced real photo; the README also contains the email address from your résumé. Uploading this package to a public repository exposes both. The optional selfie video from the guide was not supplied.
- The `profile-night-view.svg` image appears after the workflow’s first successful run. Open **Actions → GitHub-Profile-3D-Contrib → Run workflow** once to create it; later runs are scheduled daily.
- Change each `?v=1` in the README when you update its linked SVGs to refresh GitHub’s image cache.
- Text and résumé figures are static; update them when the résumé changes.
